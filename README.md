# Why Not? Cafe-bar

Marketing site for Why Not? Cafe-bar in Boothstown, Manchester.

## Dev

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

> Scripts use Turbopack because this folder name contains `?`, which breaks webpack path resolution.

## Stack

Next.js · Tailwind CSS · Framer Motion
